# toolindex-maintainer-test

A tiny command line script that prints the current date and the free disk space of the home directory. It exists to test the maintainer workflow of a software catalogue.

## Features

- Prints the current date in ISO 8601 format
- Shows the free disk space of your home directory
- Runs on any system with a POSIX shell

## Installation

```bash
git clone https://github.com/<DEIN-ZWEITKONTO>/toolindex-maintainer-test.git
cd toolindex-maintainer-test
chmod +x status.sh
```

## Usage

```bash
./status.sh
```
